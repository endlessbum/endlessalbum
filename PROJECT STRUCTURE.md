Endlessalbum — парный дневник воспоминаний
Полный список функционала и возможностей проекта:

1. Аутентификация и управление пользователями
Регистрация с username, email, паролем
Вход/Выход через сессии (express-session)
Роли пользователей: main_admin, co_admin, guest, user
Профиль пользователя: имя, фамилия, аватар, username, email
Смена профиля с валидацией уникальности username/email

2. Парная система
Создание пары — автоматически при регистрации первого пользователя (main_admin)
Присоединение к паре по инвайт-коду
Управление инвайт-кодами (генерация, отзыв, только main_admin может управлять)
Информация о партнёре: онлайн-статус, последняя активность

3. Лента воспоминаний (Home)
Создание воспоминаний: фото, видео, текст, цитаты
Просмотр воспоминаний в модальном окне
Редактирование воспоминаний
Удаление воспоминаний с автоматическим удалением файлов
Поиск по хэштегам (#), авторам (@), датам, ключевым словам
Группировка по месяцам/годам
Счётчики — виджеты для совместных целей (дни вместе, достижения и т.д.)

4. Чат
Текстовые сообщения
Изображения, видео, документы — загрузка файлов
Эфемерные сообщения — исчезают через 2 минуты (сервер контролирует время)
Голосовые сообщения — запись и отправка
Эфемерные фото/видео — камера или загрузка с обрезкой до 10 сек
Индикация «печатает...» — WebSocket real-time
Онлайн-статус партнёра — уведомления о входе/выходе
Пагинация сообщений — загрузка порциями с курсором
Фон чата — настраиваемые фоновые изображения

5. Музыкальный плеер
Загрузка аудио (MP3, WAV, OGG, M4A/AAC, FLAC, WebM) — до 200 МБ
Метаданные треков — название, исполнитель, обложка
Воспроизведение с управлением (play/pause, next/prev, перемотка, громкость)
Мини-плеер — глобальное воспроизведение
Горячие клавиши: Space, ← →, ↑ ↓, M, N/P
Избранное — список любимых треков
Альбомы — создание, управление, drag-and-drop порядок
Drag-and-drop переупорядочивание треков
Скачивание треков на устройство
Просмотр музыки партнёра — доступ к его библиотеке
Копирование треков партнёра в свою библиотеку
Синхронизация между вкладками/устройствами через localStorage

6. Мини-игры
20 вопросов — один загадывает слово, второй отгадывает
Правда или Действие — карточки с заданиями разной сложности
Ролевая игра — выбор сценария, назначение ролей, отправка сообщений
Викторина о партнёре — вопросы о предпочтениях друг друга
Real-time синхронизация через WebSocket
Приглашения в игры через уведомления

7. Настройки
Тема оформления: light/dark/system
Язык: русский, английский
Уведомления: воспоминания, сообщения, игры
Приватность: видимость для гостей, комментарии, игры
Дата начала отношений — для счётчиков

8. Профиль
Просмотр профиля со статистикой (воспоминания, сообщения, игры, дни вместе)
Редактирование профиля
Загрузка аватара (JPG, PNG, GIF, WebP до 15 МБ)
Просмотр музыки партнёра

9. Загрузки и файлы
Аватар — загрузка с валидацией типа и размера
Изображения воспоминаний — до 10 МБ
Видео воспоминаний — до 200 МБ
Документы — PDF, Word, Excel, PowerPoint, архивы до 50 МБ
Аудио — до 200 МБ
Голосовые сообщения — до 10 МБ
Обложки альбомов — до 15 МБ
Локальное хранилище в public/uploads/
Защита от path traversal атак

10. Безопасность
Валидация на сервере (Zod) — все входящие данные
Rate limiting — общий и строгий для авторизации/загрузок
WebSocket rate limiting — защита от перегрузок
CSRF защита (helmet)
Сессионная аутентификация — express-session
Эфемерные сообщения — сервер контролирует время жизни
Path traversal защита при удалении файлов
Валидация MIME-типов файлов

11. Real-time функции
WebSocket сервер (/ws)
Heartbeat — проверка активности соединений
Индикация онлайн-статуса
Typing indicators
Синхронизация игр между игроками

12. API эндпоинты
/api/health — проверка здоровья сервера
/api/version — версия приложения
/api/memories — CRUD воспоминаний
/api/messages — CRUD сообщений с пагинацией
/api/partner — информация о партнёре
/api/profile — профиль пользователя
/api/settings — настройки пары
/api/couple/* — управление парой и инвайтами
/api/counters — счётчики
/api/games — игры
/api/upload/* — все загрузки файлов
/api/audios — управление аудио

13. База данных
PostgreSQL через Drizzle ORM
In-memory хранилище для разработки без БД
Схемы: users, couples, memories, comments, messages, games, counters

14. UI/UX
Минималистичный дизайн — стеклянные панели (glass effect)
Адаптивная вёрстка — mobile-first
Нижняя навигация — мобильная навигация
Анимации (Framer Motion)
Reduced motion — уважение системных настроек
Hot‑keys — клавиатурные сокращения

15. Тестирование
Playwright E2E тесты
Vitest юнит-тесты
Smoke tests — быстрая проверка хранилища
A11y smoke — проверка доступности

16. Архитектура
Frontend: React + Vite + Tailwind + Wouter + TanStack Query
Backend: Node.js + Express + WebSocket (ws)
Database: PostgreSQL + Drizzle ORM (или in-memory)
Validation: Zod
File storage: локальное (public/uploads/) или облачное
